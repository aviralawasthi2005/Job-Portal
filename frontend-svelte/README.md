# SvelteJS Healthcare Job Portal Client

A modern reactive web client for the Healthcare Job Portal built with **Svelte 4/5**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## ✨ Features
- **Ultra-Fast Reactive UI:** No Virtual DOM overhead; sub-second load times.
- **Healthcare Design System:** Glassmorphic navigation, medical emerald & teal palettes, responsive job cards, and interactive modal dialogs.
- **Live Filtering:** Instant client-side & server-side search across nursing, telehealth, physicians, pharmacy, and health informatics.
- **Direct Application Submission:** Fast-track candidate intake form that triggers the n8n automation pipeline.
- **Employer Job Posting:** Instant post dialog with client validation that broadcasts to Discord and Slack via n8n.

## 🛠️ Development & Build

```bash
# From monorepo root:
npm run dev:svelte

# Or inside frontend-svelte:
cd frontend-svelte
npm install
npm run dev
```

Visit the Svelte portal at [http://localhost:5174](http://localhost:5174).
